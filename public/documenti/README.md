# 📄 Cartella Documenti

Questa cartella contiene i documenti legali e informativi del sito.

## 📋 Come Usare

1. Carica i tuoi documenti PDF o DOCX in questa cartella
2. Vai su CMS → Frontend
3. Inserisci il percorso del documento (es: `/documenti/privacy-policy.pdf`)
4. Salva le impostazioni

## 📁 Documenti Consigliati

- `privacy-policy.pdf` - Privacy Policy
- `cookie-policy.pdf` - Cookie Policy
- `termini-condizioni.pdf` - Termini e Condizioni
- `gdpr.pdf` - Informativa GDPR

## 🔗 Accesso ai Documenti

I documenti saranno accessibili pubblicamente tramite URL:
- `https://tuosito.com/documenti/privacy-policy.pdf`
- `https://tuosito.com/documenti/cookie-policy.pdf`
- ecc.

## ⚠️ Note Importanti

- I file in questa cartella sono PUBBLICI
- Non caricare documenti sensibili o riservati
- Usa nomi file senza spazi (usa trattini: `privacy-policy.pdf`)
- Formati supportati: PDF, DOCX, DOC, TXT
